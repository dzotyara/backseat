# Backseat

Бот для группового чата в Telegram, который сам решает, когда встрять
с комментарием — следуя заданному поведенческому промпту (например
«хейти этого участника» или «говори, какой этот участник хороший»).
Использует `deepseek-ai/deepseek-v4-flash-0731` через GonkaGate API.

## Как это работает

Бот не спрашивает модель на каждое сообщение — это дорого и упирается
в лимиты GonkaGate. Вместо этого он проверяет, стоит ли комментировать,
только по одному из поводов:

- **По расписанию** — раз в случайное число сообщений от
  `MIN_MESSAGES_BETWEEN_COMMENTS` до `MAX_MESSAGES_BETWEEN_COMMENTS`
  (интервал перевыбирается заново после каждой проверки).
- **Упоминание/ответ** — если бота тегнули (`@username`) или ответили
  на его сообщение, он почти всегда отвечает, минуя расписание и
  кулдаун.
- **Явный вопрос** — если последнее сообщение похоже на вопрос
  (заканчивается на «?»), бот проверяет, стоит ли ответить, даже если
  расписание ещё не подошло.

Во всех случаях финальное решение — комментировать или промолчать —
и сам текст комментария выбирает модель, исходя из `BOT_PROMPT` и
истории переписки.

Есть защитный кулдаун `MIN_SECONDS_BETWEEN_COMMENTS`, чтобы бот не мог
писать слишком часто подряд (не действует на упоминания/ответы).

## Команды бота

- `/start` — короткое объяснение, как бот работает
- `/help` — список команд
- `/ping` — проверка, что бот жив (ответит `pong`)
- `/status` — текущие настройки (интервал, окно контекста, сколько
  сообщений осталось до плановой проверки в этом чате)

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `GONKAGATE_API_KEY` — ваш ключ GonkaGate
   - `GONKAGATE_BASE_URL` — базовый URL GonkaGate API (если отличается
     от дефолтного, поправьте)
   - `BOT_PROMPT` — поведение/характер бота, свободный текст
   - остальные параметры (интервал комментариев, окно контекста,
     лимит входных токенов, кулдаун) — опциональны, дефолты разумны

2. Запуск одной командой:

   ```bash
   docker compose up -d --build
   ```

3. Добавьте бота в нужный групповой чат и отключите privacy mode
   у @BotFather (`/setprivacy` → Disable), иначе бот не будет видеть
   сообщения других участников, а не только адресованные ему.

Промпт (`BOT_PROMPT`) и остальные настройки меняются в `.env` и
применяются после перезапуска контейнера (`docker compose restart`).

## Файлы

- `bot.py` — aiogram-хендлеры сообщений и команд, буфер истории чата
  по каждому чату, логика "когда вообще спрашивать модель"
- `llm_client.py` — клиент для OpenAI-совместимого `/chat/completions`
  эндпоинта GonkaGate; парсит JSON-решение модели
  (`{"should_comment": bool, "comment": str}`), ограничивает
  параллельные запросы (`GONKAGATE_MAX_CONCURRENCY`) и даёт грубую
  оценку токенов для обрезки контекста (`MAX_INPUT_TOKENS`)
- `docker-compose.yml` / `Dockerfile` — запуск одной командой

## Важно про GonkaGate

Реализация предполагает, что GonkaGate предоставляет OpenAI-совместимый
эндпоинт `/chat/completions`. Если формат запроса/ответа у GonkaGate
отличается — понадобится поправить `llm_client.py` под реальный API.

GonkaGate также ограничивает число **одновременных** запросов
(отдельно от лимита в минуту) — если увидите ошибку вида
`rate limit exceeded: too many concurrent requests`, убедитесь, что
`GONKAGATE_MAX_CONCURRENCY` не превышает лимит вашего тарифа.
